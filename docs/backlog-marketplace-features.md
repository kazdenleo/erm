# Бэклог: функции из сравнения с сервисами для селлеров

Отложенные идеи (октябрь 2026). Источники сравнения: MPStats, Moneyplace, Маяк, SellerFox, SelSup, XWAY, MP Manager, MPZORRO, РевизорБОТ, НеОтдам.

## Финансы
- **ДДС и календарь выплат** — прогноз выплат маркетплейсов (WB еженедельно, Ozon дважды в месяц), оплаты поставщикам, предупреждение о кассовом разрыве.
- **План/факт** — план выручки и прибыли на бренд/категорию/товар, отслеживание выполнения.
- **Себестоимость по FIFO (партионный учёт)**, учёт баллов Ozon и СПП WB в выручке.
- **«Рука на пульсе»** — лента заказов и продаж за сегодня в сравнении со вчера и прошлой неделей.
- **Платёжный календарь с поставщиками** — отсрочки, кредиторка/дебиторка, связка с ДДС.

## Аудит маркетплейсов
- **Поиск потерянного товара** — сверка цепочки «поставка → приёмка → продажа/возврат → компенсация» по каждой единице.
- **Генерация претензий и обращений** через GigaChat по найденным расхождениям.

## Реклама
- Биддер WB / Ozon / Я.Маркет: удержание ДРР или CPC, расписание показов, лимиты бюджета.
- Аналитика поисковых запросов и кластеров в рекламе, минус-слова.
- Рекламные расходы в юнит-экономике по каждому SKU на всех площадках.
- Автопауза рекламы при нулевом остатке и автовключение при появлении.

## SEO и карточка
- **Воронка по товару**: показы → переходы → корзина → заказ → выкуп с конверсиями (WB nm-report, Ozon Analytics).
- Мониторинг позиций по ключевым запросам и регионам (свои и конкуренты).
- Подбор запросов/кластеров, проверка ключей в карточке, генерация описания под кластеры (GigaChat).
- A/B-тест главного фото.

## Цены и акции
- **Участие в акциях с расчётом прибыли** при акционной цене (сейчас только просмотр и вывод из автоакций Ozon).
- Ценовой индекс Ozon и рекомендации для «выгодной» цены.
- Цена для покупателя после СПП и скидок МП в сравнении с конкурентами.
- Акции Я.Маркета.
- **Уведомление «тарифы изменились → эти SKU стали убыточными»** (сравнение ночных снимков комиссий/тарифов).

## Поставки FBO и логистика
- Прогноз и раскладка по складам/кластерам для Ozon и Я.Маркета.
- Индекс локализации Ozon и коэффициенты логистики WB: переплата и рекомендация кластера.
- Мониторинг коэффициентов приёмки WB (бесплатные слоты) с уведомлением.
- Создание поставки FBO через API вместо импорта.

## Коммуникации
- AI-ответы на отзывы и вопросы (GigaChat поверх существующих правил автоответов).
- Чаты с покупателями Ozon и WB.
- AI-сводка отзывов: частые жалобы по SKU.

## Уведомления
- **Telegram-бот**: новые заказы, сводка дня, заканчиваются остатки, штрафы, негативный отзыв, ошибки синхронизации.
- Еженедельная сводка на почту/Telegram.

## Аналитика рынка
- Ниши, тренды, продажи конкурентов — через интеграцию с API MPStats.
- Автоподбор конкурентов по категории/OEM, история их цен и остатков, оценка продаж по изменению остатков.

## Прочее
- Контроль сроков FBS: заказы, близкие к просрочке отгрузки.
- Еженедельные проактивные AI-инсайты «что изменилось и почему».
- Автозапчасти: аналоги по кросс-номерам при отсутствии, создание карточек из каталога поставщика + PartsIndex, сопоставление отзывов «не подошло» с применимостью.
- Мультиканал: Avito, Мегамаркет, свой сайт.
